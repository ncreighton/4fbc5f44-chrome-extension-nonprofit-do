# Chrome Extension: Nonprofit Donor Research and Grant Prospecting Tool

A Chrome extension for nonprofit development officers and grant writers that enriches donor and foundation profiles in real-time while browsing LinkedIn, foundation websites, and giving databases. Shows estimated giving capacity, past grant history to similar organizations, board member relationships, and open grant deadlines from Foundation Directory data. Generates one-click prospect summary reports for donor stewardship meetings.

## Installation

### Chrome
1. Download and extract the ZIP
2. Go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extracted folder

### Firefox
1. Download the Firefox version
2. Go to `about:debugging`
3. Click "Load Temporary Add-on"
